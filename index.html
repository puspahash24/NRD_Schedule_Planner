How to use

  1. Load the latest Blasthole Map (KML/KMZ). Holes show coloured by Fe.
  2. Optionally add a face-string KML (tick “add to loaded”). Lines become tappable.
  3. Tap a face on the map. Nearby holes are ringed and their average quality shows here.
  4. Name it, save it to inventory, and add it straight to a plant.
Pick a face — quality fills from inventory. Overwrite a value for this plant only (yellow); clear it to revert.
